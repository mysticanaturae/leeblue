# LEE BLUE POMONA — multilingual website

Static website prepared for deployment.

## Languages
- English: `/` (`index.html`)
- Slovenian: `/sl/`
- Spanish: `/es/`

## Files
- `index.html`, `sl/index.html`, `es/index.html` — language pages
- `style-v2.css` — shared styles
- `script.js` — navigation and multilingual stay-price estimate
- `images/` — image assets

## Deploy
Import this folder into Vercel as a static site. No build command is required; the output directory is the project root.
